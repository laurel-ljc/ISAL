## 1. 决策

新增 Gym 环境任务 `ISAL2-RPO-AME-Sparse-v0`，以薄子类继承现有 AME。
该任务内部用 `acquire` / `robust` 两个阶段预设切换课程。
地形、命令、噪声、评估场景分别配置，不为每个 checkpoint 或每个地形创建一份任务。

单纯查看新地形，可以在原 AME 上换 terrain preset；本方案还涉及路线感知的出生位置、命令、
成功/停滞/掉梁判定和升降级，因此需要独立行为配置。保留现有 AME 和 rough/rough_hard 作回归基线。
复用物理步进、PD 控制、观测缓存、AME 网络、PPO 与 ONNX 导出。

目标是先让策略可靠获得稀疏支撑面上的成功经验，再学习噪声与扰动下的鲁棒性。
以下比例、宽度、门槛和训练预算是针对 RPO 的工程起始建议，未经训练验证，不是论文原参数或效果承诺。

## 3. 第一阶段 acquire：理想感知下补齐技能

### 3.1 地形混合

使用 8×8 m 地形块、10 个难度等级、20 列；比例为 5% 的整数倍，便于实际列分配。

| 类型 | 比例 | 用途 |
|---|---:|---|
| 单直梁 single_beam | 30% | 正面接近梁、上梁、持续沿梁前进、下梁 |
| 放射梁 radial_beams | 20% | 从中央安全平台选择可行方向，练习星形梁技能 |
| 分离踏石 grid_stones | 15% | 与连续底面 random grid 分开，实现真正的稀疏落脚 |
| 单沟 single_gap | 10% | 在可达步长内跨越负障碍 |
| 托盘 pallets | 5% | 有间距的平台序列 |
| 平地 | 10% | 保留正常行走、站立和全向控制能力 |
| 温和楼梯 | 5% | 常规地形复习 |
| 温和粗糙地面 | 5% | 常规地形复习 |
| 合计 | 100% | |

放射梁保持与现有星形梁相近的中央平台和放射结构，但显式提供安全出生区域、出口区域和路线元数据。
外围安全区域应足够完成退出动作。原 rough_hard 的 star 另作固定回归测试，不能仅靠新放射梁成绩宣称解决了旧地形。

### 3.2 难度范围

关键改进是新增当前 40 cm 梁之前的容易档，而不只是继续增加难度等级数量。

| 等级 | 梁宽（m） |
|---|---:|
| 0 | 0.80 |
| 1 | 0.70 |
| 2 | 0.60 |
| 3 | 0.55 |
| 4 | 0.50 |
| 5 | 0.45 |
| 6 | 0.40 |
| 7 | 0.35 |
| 8 | 0.30 |
| 9 | 0.25 |

第一版单梁无侧向支撑区长度固定约 3 m，只按表收窄梁宽，避免同时改变两个几何变量。
若等级 0 仍难获得成功，启用补救长度课程：固定宽 0.80 m，长度 1→2→3 m，每档通过后再增加；
完成后回到宽度课程。4 m 长梁作为额外验证和后续长度扩展。
放射梁长度受中央平台和外缘几何限制，不能直接套用单梁跨度。

其他地形起始范围：

- 踏石宽 0.60→0.30 m，间距 0.10→0.20 m，先等高，再在 robust 阶段增加高度变化。
- 托盘可落脚宽度 0.80→0.35 m，间距 0.10→0.25 m。
- 单沟宽 0.10→0.30 m；需要更容易入口时增加无沟复习样本，不依赖小于地图分辨率的沟让编码器学习。
- 第一版坑深固定，优先沿可落脚面积和距离调整难度。训练网格需设置真实缺口，不能用覆盖缺口的碰撞底面替代。
- 25 cm 是待验证的目标宽度；先测量 RPO 足部碰撞几何与可达落脚范围，再确认最高档物理上可行。

生成器必须导出：安全出生区域、路线切向/侧向、入口/出口、可支撑区域、坑底高度、名义难度和实际参数。
有效地形不应依赖某个固定高度扫描相位；评估时覆盖地图采样网格相对边缘的不同偏移。

### 3.3 感知与随机化

- `noise.add_noise=False`：关闭 actor 高度图和本体观测加噪；critic 保持原干净特权观测。
- 扫描位置漂移为 0。
- 首轮 A/B 关闭 push 事件，并使用相同名义质量、COM、增益、关节参数和接触材料。
- 首轮出生速度为 0，关节初始扰动明显收小；保留小范围且确保双脚安全着地的位置扰动。
- “无观测噪声”与“无动力学随机化”是独立开关，必须分别写入最终配置，不能用一个名字隐式控制全部。

### 3.4 命令与出生课程

| 档位 | 稀疏地形上的设置 |
|---|---|
| C0 对齐通过 | 面向可行路线；yaw 扰动约 ±5°；沿路线前进 0.35～0.65 m/s；不采样独立横移或任意转向 |
| C1 对齐修正 | 已掌握的几何难度上，将 yaw 扰动扩大到约 ±15°，增加安全范围内的横向出生偏差和小幅指令扰动 |
| C2 多方向控制 | 分开采样前进、侧身沿梁、转向等行为；先在较宽支撑或平台上练，再逐步缩窄 |

平地/温和地形继续保留站立、横移、转向命令。稀疏地形 C0 不混入零指令回合。
出生点依据足部支撑条件采样，不能直接沿用随机 yaw ±π 与 x/y ±0.5 m。

C0 的稀疏地形前進命令在一次通过尝试内固定，不在中途每 10 s 随机改方向。
路线方向转换为机器人当前 yaw 坐标系下的速度指令；不要错误地把恒定 body-x 当作恒定沿梁方向。
C0 可用明确的 heading 控制帮助对齐；它属于训练命令采样器，不增加 actor 输入。

“横移”必须说明参考系：侧身沿梁行走是可行技能，直接要求横穿窄梁边缘则可能不可行。
无法实现的指令只放入独立拒绝/保持平衡评估，不按速度跟踪误差强迫机器人执行。

命令难度与几何难度分开升级。学习 C1/C2 时保留 C0 样本，先退回已能通过的较宽支撑面。

## 4. 升降级、结束与评估语义

### 4.1 训练难度

- 所有环境从等级 0 起步，即 `max_init_terrain_level=0`。
- 按地形类型保存能力等级、当前分配等级及最近结果，不使用所有地形合并的平均等级决定升级。
- 起始规则：连续成功 2 次升一级，连续失败/未通过 2 次降一级，均限制在该类型允许范围内。
- 保留约 20% 的容易档回放：临时采样低于能力等级的地形，不用这些容易回合的成功直接提升能力等级。
- 固定验证集上的当前档通过率达到建议门槛 85%、跌落率低于 10%，连续两次评估满足后，才放开下一档。
- 门槛是调试起点；同时报告样本数和置信区间，不能把少量成功当作充分证据。

### 4.2 结果定义

1. `success`：穿过该路线出口检测面，支撑脚已落在有效出口支撑区域，并稳定约 0.3 s；不是从出生点随意移动 4 m。
2. `fall_or_invalid_support`：继承原身体碰撞终止，另检测带负载的脚落在坑底/无效支撑面，以及确实离开指定可通行区域的绕路。
3. `stuck`：有有效移动指令时，预热期之后连续约 3 s 的沿路线进度不足 0.1 m。
4. `timeout_without_success`：20 s 仍未通过；需区分正在缓慢移动与停滞。

stuck 是观测指标，第一版不因触发它立即终止，也不立刻新增惩罚，以免混淆课程和奖励效果。
摆动脚在空中经过坑上方不能判为无效支撑；判断必须结合接触/承载状态和地形几何。
绕行测试依据完整通行走廊与接触记录，不能用比梁还窄的 COM 走廊误杀合理平衡动作。

通过出口后可以提前重新采样，但它是连续速度跟踪任务的人为截断：返回 truncated 并从重置前 terminal_observation 做 bootstrap。
身体碰撞/落入坑底等真实失败返回 terminated，不 bootstrap。达到 20 s 是时间截断。
若失败与通过同一步发生，失败优先。保留原 reset 历史刷新和终态观测顺序，并做针对性测试。

首轮不新增通过奖励；成功判定用于课程、采样和报告。这些改变对两组 A/B 完全一致。

## 5. 两个 checkpoint 如何公平对照

对应用户选中的方案：rough_hard 和稳定 rough checkpoint 在相同无噪声宽梁课程上等量训练，按通过/停滞/跌落选择起点。

### 5.1 初始化

- A：`outputs_download/rpo_ame/ISAL2-RPO-AME-v0-Rough/model_9001.pt`。
- B：`outputs_download/rpo_ame/ISAL2-RPO-AME-v0-Rough-Hard/model_18002.pt`。
- 对照的含义是“现有哪个初始化更适合继续训练”，不是比较两条路线的历史总样本效率；B 已经历更多历史训练。
- warm-start：加载 actor、critic、地图编码器及各自的观测归一化统计。
- 两边重新创建优化器，显式使用相同学习率 1e-4、相同 PPO 参数和 entropy_coef=0.005；课程等级与本次更新计数均从 0 开始。
- 首轮将动作采样标准差显式设为相同的 0.30（策略 action 单位，乘 action_scale 后约 0.075 rad），作为待验证初值。
- 上述标准差统一用于控制探索差异；加载后必须检查实际值。不能仅修改 `init_noise_std`，因为 load_state_dict 会恢复 checkpoint 的值。
- 保留各自正常化统计，它们与各自策略权重共同构成有效初始化，不盲目清零。
- 完整 resume 与 warm-start 是两个显式模式。resume 恢复优化器、探索参数、课程与随机数状态；warm-start 按上述策略重新初始化训练状态。

### 5.2 小规模筛选

- 首轮每组 1024 环境、每次 rollout 24 步、500 次新 PPO 更新，约 1228.8 万环境转移/组。
- 两组采用相同种子、地形生成参数、命令规则、奖励和更新预算；不要用 wall-clock 时长替代样本量。
- 在更新 0、250、500 进行确定性评估，关闭探索、保持评估时归一化统计冻结。
- 初筛固定 384 个场景：单梁、新放射梁、原 rough_hard 星形梁，分别 4 个该类型适用难度，每档 32 个出生/命令组合。
- 单梁/新放射梁可用宽度 0.80、0.60、0.40、0.25 m；原星形梁按原配置取易、中、较难、最高档，不人为扩宽原测试地形。
- 测试场景单独固定种子和参数，不与训练地形样本复用。相同 seed 不保证两条训练轨迹相同，固定评估场景才是可比较的依据。
- 相同升级规则即可；策略能力不同导致训练阶段进度不同是实验结果，不强迫两组遇到完全相同的自适应难度轨迹。
- 结果接近或置信区间重叠时，再增加种子与预算，而不是凭很小的通过率差异定胜负。

主要指标：每类型/难度的通过率、跌落率、停滞率、通关时间、沿路线位移，以及常规地形速度跟踪退化。
成功率必须包含所有尝试，不能只统计存活样本。原星形梁和目标单梁结果单独显示，不能被宽梁成绩稀释。

若两组都几乎不动：先检查指令实际值、出生有效性、地图扫描、几何可达性和探索；再降低起始难度。
只有这些通过后才开展独立奖励消融，如调整速度跟踪与动作正则的比例。不要在 A 组和 B 组使用不同奖励补救后再宣称起点优劣。

## 6. 第二阶段 robust：已有技能上的鲁棒微调

第一阶段的目标单梁与原星形梁在固定验证集上已有可靠通过能力后，才进入 robust。
可用建议门槛：主要目标难度通过率达到约 85%、跌落率低于 10%，并通过平地行走回归；
达到门槛的判断覆盖多个随机场景，不由训练平均奖励或固定迭代编号决定。

先在已掌握地形上加噪，再增加拓扑难度，不同时改变所有因素。

1. actor 高度噪声依次 0→±0.005→±0.010→±0.025 m；本体噪声按原配置的 0→25%→50%→100% 缩放。
2. 恢复质量、COM、摩擦、增益等随机化；推扰单独从弱开始增加，每次只解锁一个因素组。
3. 地图 XY 漂移单独控制，先测试 ±0.01 m，再考虑 ±0.02 m；漂移采用每回合固定偏差，不能实现成每帧独立位置跳变。
4. 每次改变后复评。通过率相对进入该档前下降超过建议 10 个百分点时暂停升级、增加容易档比例，并定位原因。
5. 稳定后，混合为 80% 基础类 + 20% 新类型。具体为单梁 20%、放射梁 15%、分离踏石 10%、
   单沟 10%、托盘 5%、平地 10%、温和楼梯 5%、粗糙地面 5%、单列踏石 10%、连续沟 10%。
   合计 100%，仍可用 20 列准确分配。其他未训练结构保留为泛化测试。

所有坡度/噪声/扰动调度使用“本次微调的新更新数”和阶段状态，不使用 checkpoint 的历史 9001/18002 编号。
阶段、能力等级、回放分配、噪声档位、近期统计和 RNG 状态应进入 checkpoint，确保同任务真正 resume 时连续。

## 8. 实施验收顺序

1. 生成每个新地形的最低/中间/最高档截图；检查射线高度、支撑尺寸、安全出生区域与缺口。
2. 验证路线方向变换、命令实际值、足部支撑判定、成功/失败优先级和停滞标记；摆动脚经过坑上方不误判。
3. 测试升降级、容易档回放不误升级、阶段状态保存/恢复和两个 warm-start checkpoint 的严格兼容加载。
4. 测试 successful truncation/time-limit 的终态 bootstrap 与真实失败不 bootstrap，以及 reset 后历史无污染。
5. 小批量物理 smoke test：有限观测、有限奖励、无空射线 NaN 漏出、reset 与课程一致。
6. 再启动两组等量初筛。实际训练资源与输出目录单独明确，不由本设计文档自动启动训练。
